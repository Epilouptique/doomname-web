Art. 3 Description du service

DoomName est un service web de surveillance de noms de domaine proposant les fonctionnalités suivantes :

  • Vérification WHOIS en temps réel de la disponibilité d'un nom de domaine
  • Abonnement à des alertes e-mail envoyées lors d'un changement de statut
  • Gestion des alertes via un lien d'authentification sécurisé (magic link)
  • API publique v1 accessible sur demande d'une clé (dk_xxx)
  • Application Progressive Web App (PWA) installable sur mobile et bureau

Les limites techniques actuelles sont : 50 alertes actives et 200 alertes au total par adresse e-mail ; 100 requêtes par jour pour les clés API.

Le service est actuellement proposé gratuitement, sans engagement et sans garantie de pérennité à ce niveau tarifaire. L'éditeur se réserve le droit d'introduire des offres payantes avec préavis.
